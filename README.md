This is a varta backend in nestJs for chatapp and soket api. This is with authentication and autheration where user can make friend and chat  sharing images to his friend.


# Varta API (NestJS)
This is the backend API for the Varta application.

## 🚀 Features
* Authentication & Authorization
* Chat (WebSocket support)
* Follow system
* REST APIs
* NODE MAILER
* CLOUDINARY FOR ASSETS

## 🛠️ Tech Stack

* NestJS
* Node.js
* MongoDB
* Socket.IO

## 📦 Installation

```bash
npm install
```

## ▶️ Run Project

```bash
npm run start:dev
```

## 🌐 Environment Variables

Create a `.env` file and add:

```
PORT=3000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret
JWT_EXPIRES = any_expiry_time

CLOUDINARY_API_KEY = key
CLOUDINARY_SECRET_KEY Key
CLOUDINARY_NAME = name

MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USER= mailId
MAIL_PASS= passKey
```

## 📡 API Base URL

```
http://localhost:3000
```
